# Third-party licenses for `python-scripts/timm`

This directory records the third-party software used by the timm training and
ONNX export scripts. Versions are taken from the repository's `uv.lock` file.

Before shipping a release, keep this directory with the application or its
installer and update it whenever `uv.lock` changes. The pretrained model and
dataset are separate assets and are not covered by these software licenses.

The selected `timm` MobileNetV3 weights are ImageNet-1K derived. Review the
weight and dataset terms separately before commercial use.
